# Custosell - Tutorial Production Order

The order in which the 287 tutorials should be **made** (recorded, edited, and
published). Ordering logic:

1. **Group by tier** - Tier 1 first (new users get value fastest), then Tier 2, then Tier 3.
2. **Group by module prefix** - within a tier, modules follow the new-user journey order
   (ACC -> SET -> INV -> POS -> DSH -> SHF -> OFL -> EXP -> CUS -> MKT -> EST -> ACT ->
   DOC -> PIP -> STR -> HRM -> FCT -> SUB -> REF -> NOT -> QNT -> GDE).
3. **Within each module** - in sequence (01, 02, 03, ...).

**Total tutorials: 287**
